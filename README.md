# Neon Wolves — сайт киберспортивной команды на Django

## Структура проекта

```
esports_site/
├── manage.py
├── requirements.txt
├── db.sqlite3                  (создастся после миграций)
├── esports_site/                # настройки проекта
│   ├── settings.py
│   ├── urls.py
│   ├── wsgi.py
│   └── asgi.py
├── team/                        # приложение "команда"
│   ├── models.py                # модели Player и Match
│   ├── views.py                 # главная, профиль игрока, матчи
│   ├── urls.py
│   ├── admin.py                 # админка для добавления игроков/матчей
│   ├── templates/team/          # HTML-шаблоны
│   │   ├── base.html            # общий каркас: шапка, меню, футер
│   │   ├── home.html            # главная: hero + сетка игроков
│   │   ├── player_detail.html   # страница одного игрока
│   │   └── matches.html         # расписание матчей
│   └── static/team/
│       ├── css/style.css        # киберспортивный неоновый стиль
│       └── js/script.js         # мобильное меню
└── media/avatars/                # сюда сохраняются загруженные аватарки
```

## Как всё запустить

### 1. Установи Python
Нужен Python 3.10+. Проверь версию:
```
python --version
```

### 2. Создай виртуальное окружение и активируй его

Windows:
```
python -m venv venv
venv\Scripts\activate
```

macOS / Linux:
```
python3 -m venv venv
source venv/bin/activate
```

### 3. Установи зависимости
```
pip install -r requirements.txt
```

### 4. Примени миграции (создаст базу данных db.sqlite3)
```
python manage.py makemigrations
python manage.py migrate
```

### 5. Создай администратора (для входа в админ-панель)
```
python manage.py createsuperuser
```
Введи логин, email (можно пропустить) и пароль.

### 6. Запусти сервер разработки
```
python manage.py runserver
```

Сайт будет доступен по адресу: **http://127.0.0.1:8000/**
Админ-панель: **http://127.0.0.1:8000/admin/**

## Как добавить игроков и матчи

1. Зайди в **http://127.0.0.1:8000/admin/** и войди под своим суперпользователем.
2. Открой раздел **Игроки** → **Добавить**.
   - Заполни никнейм, роль, загрузи аватар (фото игрока), при желании — описание, соцсети, дату вступления.
   - Отметь галочку "В основном составе", чтобы игрок появился на сайте.
3. Открой раздел **Матчи** → **Добавить**, чтобы добавить прошедшие и будущие игры (результат: победа / поражение / предстоящий).
4. Обнови главную страницу — карточки игроков и ближайшие матчи появятся автоматически.

## Что можно доработать дальше

- Добавить страницу новостей команды (модель `News` + шаблон по аналогии с матчами).
- Подключить загрузку нескольких фото на профиль игрока (галерея).
- Добавить турнирную статистику (K/D, винрейт и т.д.) в модель `Player`.
- Заменить SQLite на PostgreSQL и задеплоить на хостинг (Render, Railway, VPS) — для продакшена также поменяй `SECRET_KEY`, `DEBUG=False` и `ALLOWED_HOSTS` в `settings.py`.
- Настроить раздачу медиафайлов через Nginx или облако (S3) при продакшен-деплое, так как текущая раздача через Django работает только при `DEBUG=True`.

## Технологии
- Django 5
- SQLite (по умолчанию, легко меняется)
- Pillow (для работы с изображениями аватаров)
- Чистый CSS/JS (без фреймворков) — шрифты Orbitron + Rajdhani с Google Fonts
